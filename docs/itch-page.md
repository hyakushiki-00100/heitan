## アップロードの手順(あなたの作業)
1. `npm install` のあと `npm run package` → `out/release/hyoro-b-kakuu-<版>.zip` ができる
2. itch.io で新しいプロジェクトを作る。Kind of project: **HTML**
3. Uploads に zip を上げ、「This file will be played in the browser」にチェック
4. Embed options: 幅 1200 × 高さ 820 程度(PC 向け)。「Mobile friendly」はスマホ幅で動くことを確認済みなので入れてよい。「Fullscreen button」を入れると狭い画面で遊びやすい
5. ストアページに下の文章とスクリーンショット(`npm run screenshots` の `out/screenshots/`)を載せる
6. 公開前に「Draft」で自分で遊んで確かめる

## 確認済みのこと(itch.io と同じ形で試した)
- 別オリジンの iframe の中・深いサブフォルダ(`/html/12345/index.html`)で、最後まで遊べる。保存(最高得点)・用語集・共有文字列の読み込みも動く
- 注意: 結果画面の「この展開をもう一度」のリンクは、ゲームの配信元の URL を指す(ストアページではない)。開けば遊べるが、ストアページには戻らない

## ストアページの文章(下書き)

### タイトル
兵糧奉行(試作)

### 短い説明(Short description)
戦は勝てる。だが、兵は飢える。— 前線の陣に米を運び、兵を無事に帰す兵站シミュレーション。

### 本文
あなたは本陣の兵糧奉行。戦うのは前線の兵、あなたの仕事は**米を届けること**です。

- **運ぶ人も食べる**: 運搬隊の人足も道中で米を食べます。遠いほど届く量が減ります
- **帰るまでが遠征**: 20日間陣を保ったら撤退。撤退の米が足りないと兵が離脱します
- **多めに運べば安心、ではない**: 蔵の外に余った米は「村への負担」として減点
- **道を選ぶ**: 速いが川越えのある道、遅いが安全な山道、野伏せりの出る道
- **薪・塩味噌・馬と飼い葉**: 米だけ運んでも陣は保てません
- **ルールカードで自動化**: 帰路分を残す・中継経由・護衛付き・現地調達

シナリオ3本(入門・薪と塩・馬と遠い陣)。人は死にません(離脱・負傷で表します)。
シード番号と共有文字列で、同じ展開を友だちと競えます。

### 操作
- 右の一覧で運搬隊を選び、行き先・道・積む量を決めて「出発させる」
- 「▶ 進める」で時が進みます(半日ごと)。×1/×2/×4 で速さを変えられます
- 用語に点線があれば、マウスを乗せる・押すと説明が出ます
