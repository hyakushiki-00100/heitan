## 2026-11-17 フェーズ1-3(帰り道の補給と余剰物資の減点)

### 判定ポイント(§9-1-2)について
- 人による「3分遊んで面白いか」の判定は**まだ済んでいない**。§9 でこの判定が止めるのは「カードを足す」1-4 なので、1-3 は先に進めた
- 1-4(ルールカード)に進む前に、この判定を行うこと

### 入れたもの
| 仕組み | 中身 |
|---|---|
| 軍勢 | 陣に兵24人。保持中は陣の米を1日12食べる(`army` をシナリオに追加。陣の消費はここから計算する) |
| 撤退 | 20日目に自動で撤退を始める。撤退路は陣→蔵の最短経路(陣→河原→蔵・5日)。兵も道中で食べる |
| 帰り道の補給 | 兵が持てるのは1人2まで(計48)。撤退に要る60に足りないので、撤退路の拠点(河原)に置き米が必要 |
| 受け取る量 | 兵が受け取るのは「残りの道のりに要る分」まで。多く置いた米はその場に残る |
| 離脱 | 撤退中に米が足りないと、食べられなかった兵のうち半日ごとに25%が離脱する(人は死なない) |
| 運搬隊の食料切れ | 道中で食料が尽きた隊は、その場で離脱して動かせなくなる(以前は一瞬で戻っていた)。出発前に確認ダイアログを出す |
| 遠征の終わり | 軍勢が蔵に戻り、移動中の運搬隊がいなくなった時点 |
| 評価 | 帰還した1人につき+10点、蔵の外に残った米1につき−1点(村への負担)。陣の兵糧が尽きたら0点 |
| 画面 | 撤退路を地図に薄く表示。拠点に「撤退用 0/12」。パネルに「撤退の備え」。結果画面に内訳 |

### 途中で見つけて直した問題
| 問題 | 対応 |
|---|---|
| 米が1日分足りないだけで、兵24人が一度に全員離脱した | 食べられなかった兵の一部(25%/半日)だけ離脱するルールに変更 |
| 兵が途中の拠点の米を持てるだけ拾って持ち帰るため、多く置いても減点されなかった(§2.4「多めに運べば安心を許さない」に反する) | 残りの道のりに要る分しか受け取らないように変更 |
| 撤退路の最短経路が2本同じ日数で、どちらを通るか分からなかった | 里の村–河原を 1日→1.5日 に変更し、1本に決まるようにした |
| 出発直後の隊・軍勢の印が拠点の丸と文字に重なった | 拠点に近い印は丸の外へ押し出して描く |
